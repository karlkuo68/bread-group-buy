💡 商家完全不需要下載任何 App
印表機只要「插電 + 連上店家 WiFi」就會自動接收訂單列印指令。
商家平時用麵包系統介面就好，印表機放在角落自動工作不用管它。
📦 安裝前準備物品清單
  • 快麥雲熱敏標籤印表機（型號 E31W / E41W / E20W 等，由好糰寄出，已預先綁定）
  • 原廠變壓器（24V 1.5A，盒內）
  • 感熱貼紙紙捲（80mm × 100mm 規格）
  • 店家無線網路 SSID + 密碼，必須是 2.4GHz（5GHz 印表機不支援）
  • 任何能上網的手機 / 平板 / 筆電（用瀏覽器即可，不裝 App）
第 1 步：開機 + 裝紙捲
  1. 變壓器插到印表機背面圓孔，另一端插牆上插座
  2. 打開印表機側邊電源鍵 → 機器發出「嗶」聲 + 紅燈閃爍 = 開機成功
  3. 按印表機上方按鈕打開蓋子，放入紙捲（光滑面朝上）
  4. 把紙頭拉出 5cm，蓋上蓋子聽到「喀」一聲
  5. 按 FEED 鍵測試出紙
第 2 步：配網 — AP 模式（推薦，不用裝 App）
⚡ 流程（5 分鐘搞定）
  1. 確認印表機已開機（紅燈閃爍）
  2. 長按印表機 FEED 鍵 5 秒，聽到「嗶」聲後放開 → 進入 AP 配網模式（藍燈快閃）
  3. 用手機 / 平板打開 WiFi 設定，找到名稱類似 Kuaimai_XXXX 的網路 → 連上去（不需密碼）
  4. 等 5 秒，手機會自動跳出一個網頁（或手動開瀏覽器輸入 192.168.4.1）
  5. 網頁上選擇店家 WiFi（必須 2.4GHz）→ 輸入 WiFi 密碼 → 提交
  6. 印表機嗶 2 聲 → 紅燈轉綠燈 = 配網成功
  7. 手機重新連回店家 WiFi（剛剛連的 Kuaimai_XXXX 會自動消失）
💻 備援方式 A：USB 線 + 電腦（適合店裡有筆電的情況）
  1. 下載「快麥標籤管家」軟體：https://dyj.kuaimai.com/
  2. USB 線連印表機 + 電腦
  3. 軟體偵測到設備 → 設定頁面填 WiFi 帳密
  4. 配完拔 USB，印表機自動切 WiFi
📱 備援方式 B：手機 App（如果 AP 模式跳不出網頁）
  1. App Store / Google Play 搜尋「快麥云打印」（簡體字）下載
  2. 打開 App → 用 Ken 給的快麥帳號（17132870369）登入
  3. 點「設備管理 → 添加設備 → 掃碼」
  4. 對準印表機背面 QR Code 掃描
  5. 輸入店家 WiFi 名稱 + 密碼
  6. 等 30 秒，App 顯示「在線」 = 成功 ✅
  7. 配完後 App 可以刪除
第 3 步：取得設備 SN（序號）
  1. 翻到印表機底部，找一張白色貼紙
  2. 「序列號」那行 = SN，格式像 KME31W25160294
  3. 抄下來（或拍照傳給 Ken）
第 4 步：在麵包系統設定（Ken 操作）
  1. 登入麵包系統 → 設定 → 商家管理
  2. 找到對應商家 → 點「✏️ 編輯商家資料」
  3. 拉到底，「🖨️ 雲列印設定」區塊
  4. 填印表機序號 SN → 儲存
第 5 步：遠端驗證（Ken 操作，不用到現場）
  1. 回到本頁「📡 設備即時狀態」
  2. 點「🔄 刷新全部狀態」確認該商家顯示「🟢 在線 ✓正常」
  3. 點該商家卡片的「🧪 測試列印」
  4. 1-3 秒後印表機應該自動吐一張「✅ 測試貼紙」（請安裝人員確認有印出來）
  5. 成功 → 安裝完成 🎉
